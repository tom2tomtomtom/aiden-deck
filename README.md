## brief.html

An encrypted deck, passphrase required. The file is AES-256-GCM ciphertext under a key derived by
700,000 rounds of PBKDF2-SHA256, so nothing readable is in the source and there is nothing to find
in this repository's history. It decrypts in the browser and never leaves it.
